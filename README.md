# CodeAlpha Emotion Recognition From Speech

This project recognizes human emotions from speech audio using Deep Learning and Speech Signal Processing.

---

## Technologies Used
- Python
- TensorFlow
- Librosa
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

---

## Features
- MFCC Feature Extraction
- Deep Learning Model
- Emotion Prediction
- Accuracy Evaluation
- Confusion Matrix Visualization
- Accuracy Graph

---

## Dataset
RAVDESS Emotional Speech Audio Dataset

---

## Emotions Detected
- Neutral
- Calm
- Happy
- Sad
- Angry
- Fearful
- Disgust
- Surprised
